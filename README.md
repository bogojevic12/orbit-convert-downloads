# Orbit Convert for Windows

Public downloads — **no GitHub account or sign-in required**.

[Open downloads / Otvori preuzimanja](https://github.com/bogojevic12/orbit-convert-downloads/releases)

Choose **one** installer from the release assets:

| Installer | Size | How it works |
| --- | --- | --- |
| OrbitConvert-Setup-preview.exe | 457 MB | Complete offline installer. No internet needed during installation. |
| OrbitConvert-OnlineSetup-preview.exe | About 26 KB | Downloads and verifies the complete 457 MB package, then opens setup. |

Both install the same app with private LibreOffice and all conversion engines. After installation, conversions run locally; your documents are not uploaded. Read DOWNLOADS.md in the release for instructions. SHA256SUMS.txt contains both installer hashes.

Windows 11 x64. English / Srpski. Preview installers are unsigned; a separate clean Windows VM test is still pending.

## Srpski

Za preuzimanje **nisu potrebni nalog ni prijava**. Izaberi jedan instalater: veliki radi bez interneta nakon preuzimanja, a mali automatski preuzima isti kompletan paket. LibreOffice je uključen.

Zatvori staru Orbit Convert instancu iz tray menija pre instalacije. Posle instalacije pokreni aplikaciju iz Start menija. Prevuci fajl i kratko pritisni Ctrl za konverzije ili Alt za alate, dok držiš miš.

Ovaj repozitorijum sadrži instalatere i uputstva. Licence uključenih komponenti i linkovi ka njihovom izvornom kodu nalaze se u instalaciji.
